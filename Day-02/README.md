# Day 02 – AI Banking Customer Support Chatbot

## Project Overview
Developed an AI-powered Banking Customer Support Chatbot using Python and the Groq API.

The chatbot acts as a virtual banking assistant for ABC Bank and answers customer questions about banking services such as savings accounts, current accounts, fixed deposits, UPI, loans, and debit cards.

## Technologies Used
- Python
- Groq API
- OpenAI Python SDK
- Large Language Models (LLMs)
- Jupyter Notebook
- JSON

## Features
- Answers basic banking-related questions.
- Maintains recent conversation history.
- Supports English and Telugu responses.
- Uses a system prompt to guide chatbot behaviour.
- Includes function logging and API error handling.
- Avoids requesting sensitive information such as PIN, CVV, and OTP.

## Project Files
- `banking_chatbot.ipynb` – Jupyter Notebook containing the implementation.

## Learning Outcomes
- API integration
- Prompt engineering
- LLM-based chatbot development
- Conversation memory
- Python decorators
- Exception handling

## Note
This is an educational chatbot prototype. It is not connected to a real banking system.

API keys and other credentials should never be uploaded to GitHub.
